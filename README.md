# AI 生成 · 高保真 UI 原型

素材库「AI 生成」弹窗的高保真原型(图片/视频生成、任务队列、素材入库)。

**🔗 预览:** https://ai-generate-modal.vercel.app

## 响应式说明
Banner 右侧的图片堆叠使用 **CSS 容器查询**(以 hero 实际宽度为准,而非视口宽度)逐级缩放:

- hero ≤1100px:缩放 0.8
- ≤960px:0.66
- ≤840px:0.55(同时为文字预留右侧空间)
- ≤700px:0.44
- ≤520px:隐藏图片,hero 高度自适应

## 使用
打开 `index.html` 即可,无需构建。
